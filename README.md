# Colabore

Colabore é um sistema para pesquisas anônimas internas dentro de uma empresa. O objetivo é permitir que colaboradores respondam pesquisas sem identificação, proporcionando um ambiente seguro para feedbacks.

## Tecnologias

Este projeto foi desenvolvido utilizando:

- **React**: Biblioteca para construção da interface.  
- **Styled Components**: Estilização dos componentes de forma modular.  
- **Props e States**: Gerenciamento de dados internos dos componentes.  
- **Backend Simulado com JSON**: Os dados são carregados a partir de arquivos `.json` na pasta `/backend`.  

## Como rodar o projeto

1. Clone o repositório:  
```sh
    git clone https://github.com/seu-usuario/colabore.git
```
   
2. Acesse o diretório do projeto:  
```sh
   cd colabore
```

3. Instale as dependências:  
```sh
   npm install
```

4. Inicie o servidor de desenvolvimento:  
```sh
   npm start
```
O projeto estará disponível no navegador pelo endereço:  
**http://localhost:3000**
